# Roadmap

Crate v0.1 covers the core loop: **film → import → sort → make ready → plan → get reminded →
post**. Below is where it goes next, roughly in order of how much time each saves.

## Next up
- **Direct posting to Instagram** (Reels, photos, carousels, Stories) by uploading the export to
  temporary public storage first, which Meta's API requires.
- **TikTok** connection: direct posting through TikTok's Content Posting API (needs app review)
  and stats.
- **YouTube** connection: upload Shorts and long videos straight from Crate, with titles,
  descriptions and thumbnails.
- **Auto-captions (subtitles)** burned into vertical clips, generated from the clip's speech.
- **Find the best moment**: detect the drop or loudest crowd reaction in a long set recording and
  suggest the clip to cut.

## Time savers
- Batch: "make this whole shoot ready for Reels" in one click.
- Carousel builder from a photo set (consistent crop and order).
- Repurposing: turn one long DJ set into a week of posts (clips, a Story teaser, a YouTube upload).
- Templates: reusable text overlays, intro/outro stingers, watermark/logo.
- Track ID and release tie-in: attach a track to clips and auto-mention it in captions.
- Smart folders: "unposted keepers from the last 30 days", "crowd moments with 4+ stars".
- Watch folders (e.g. your phone's camera upload folder) and import automatically.

## Smarter planning
- Content calendar that spaces pillars out automatically and fills gaps with ideas.
- Release campaigns: pick a release date, get a 2-week rollout plan (teasers, countdown, Canvas,
  release day, thank-you post).
- Gig mode: before/during/after posts for a booking, with the promoter and venue tagged.
- Analytics across platforms, weekly report of what worked.

## For other artists (product)
- Multiple profiles/brands, and team members (manager, label).
- Camera profiles beyond Sony (Canon, Panasonic, GoPro, DJI, phone footage).
- Optional cloud sync and a mobile companion for posting on the go.
- Signed installers and auto-update; macOS and Linux builds.
- Onboarding presets for other genres and roles (producers, live acts, venue owners, promoters).
